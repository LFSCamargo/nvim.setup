# Application screenshots

`editor.png`, `git.png`, and `agents.png` are photographs of the actual Neovim setup running in a terminal, taken on 2026-10-29. Each image is 1916 × 1016 after cropping away macOS window chrome so the site's screenshot frame is not doubled.

The Files view shows the nvim-tree sidebar, editor tabs, and a Cursor Agent session. The Git view shows the asynchronous source-control sidebar, commit composer, history panel, and Codex. The AI agents view shows a live Codex CLI session in the 25% chat pane (`Codex 1`, `Agent 4`) beside the same editor. No mockups or generated pictures.

These captures include the real chat CLIs. No credentials are in the frames.
