# Application screenshots

`editor.png`, `git.png`, `layout.png`, and `agents.png` are photographs of the actual Neovim setup running in Warp on this repository, taken on 2026-10-31. Each image is 1916 × 1016 after cropping away macOS and Warp window chrome so the site's screenshot frame is not doubled.

The Files view shows the nvim-tree sidebar (Files / Git / Settings / Extensions), editor tabs, and `nvim/init.lua`. The Git view shows source control with Check Diff, the commit composer, and history beside open buffers. The layout view is the same three-pane arrangement: Git, the mid editor, and Codex. The AI agents view shows a live Codex session beside `apps/web/src/modules/home/content.ts`. No mockups or generated pictures.

These captures include the real chat CLIs. No credentials are in the frames.
