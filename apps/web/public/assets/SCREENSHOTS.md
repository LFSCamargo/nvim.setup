# Application screenshots

`editor.png`, `git.png`, `layout.png`, and `agents.png` are photographs of the actual Neovim setup running in Warp on this repository, taken on 2026-10-31. Each image is 1600 × 1000 (16:10, a Mac display proportion) and shows the full Warp window.

The Files view shows the nvim-tree sidebar (project name, then Files / Git / Settings / Extensions), editor tabs, and `nvim/init.lua`. The Git view shows source control with Check Diff, the commit composer, and history beside open buffers. The layout view is the same three-pane arrangement: Git, the mid editor, and chat. The AI agents view shows a live session beside `apps/web/src/modules/home/content.ts`. No mockups or generated pictures.

These captures include the real chat CLIs. No credentials are in the frames.
